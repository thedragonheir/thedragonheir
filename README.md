My passion is exploring and understanding what goes on "under the hood" of older games and software. I reverse engineer compiled binaries to understand how they work internally.

To achieve this, I analyze compiled code, identify functions and data structures, and investigate how the original systems operate. From there, I reconstruct their behavior into clear and readable source code.

I then verify my work byte by byte, aiming to reproduce the original game's machine code as closely as possible and preserve the original implementation with the highest possible degree of fidelity.

I love software that leaves room for curiosity. Older games are especially interesting to me because they bring graphics, networking, simulation, AI, memory management and large native codebases together in one place.

For me, reverse engineering is not just about getting something to work. I enjoy trying to understand what the original programmers intended, how their systems were designed, and then expressing that understanding again as clean, readable source code.
